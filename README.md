- **操作方式**：支援鍵盤 `A / D` 或左右方向鍵 `← →`、滑鼠左右滑動、手機觸控滑動。
- **豐富掉落道具**：

## 🚀 快速啟動遊戲

1. **直接開啟**：
   - 雙擊資料夾內的 `啟動遊戲.bat`，即可自動使用默認瀏覽器啟動！
   - 或者直接雙擊 `index.html` 即可暢玩。

2. **檔案結構**：
   - `index.html`：遊戲核心頁面與界面結構
   - `style.css`：賽博復古霓虹質感樣式與流暢動畫
   - `game_rpg.js`：人生模擬 RPG 邏輯引擎
   - `game_arcade.js`：Canvas 街機跑酷遊戲引擎
   - `meme_studio.js`：表情包工坊與音效板控制器
   - `data.js`：事件庫、成就、金句與結局資料庫
   - `sound.js`：純 Web Audio 原生合成音效與晶片音樂引擎（零外鏈、100% 離線可用）
   - `assets/wu_guoheng.jpg`：吳國亨本尊照片
   - `assets/avatarData.js`：安全本機圖像快取（杜絕 Canvas 跨域限制）
